CSV File Format

The CSV file should contain optimization output such as product quantities, profit values, and resource usage. This allows the dashboard to visualize results generated externally.

product_id product_name unit_profit Material Time Energy

J003 Additive 46 2.29 56 11.11
... (more products) ...
LIMITS 5.0 120 14.0

Note: The last row with "LIMITS" defines the maximum available values for each constraint (Material, Time, Energy).
